# 常用项目目录模板

## 1. React + TypeScript（Vite）

```
my-app/
├── public/
│   └── favicon.svg
├── src/
│   ├── assets/
│   ├── components/
│   ├── pages/
│   ├── hooks/
│   ├── utils/
│   ├── App.tsx
│   ├── main.tsx
│   └── index.css
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## 2. Node.js API 项目

```
my-api/
├── src/
│   ├── controllers/
│   ├── routes/
│   ├── middlewares/
│   ├── models/
│   ├── services/
│   ├── utils/
│   └── index.js
├── tests/
├── .env
├── .gitignore
└── package.json
```

## 3. 学习课程目录（当前项目风格）

```
stage2/
├── day01/
│   └── README.md
├── day02/
│   └── README.md
└── day03/
    └── README.md
```

## 4. 通用前端项目

```
project/
├── src/
│   ├── components/
│   ├── styles/
│   └── index.js
├── public/
├── .gitignore
├── package.json
└── README.md
```

## 5. 全栈项目（前后端分离）

```
fullstack-app/
├── client/               # 前端
│   ├── src/
│   │   ├── components/
│   │   ├── pages/
│   │   └── main.tsx
│   └── package.json
├── server/               # 后端
│   ├── src/
│   │   ├── routes/
│   │   └── index.js
│   └── package.json
├── .gitignore
└── README.md
```
